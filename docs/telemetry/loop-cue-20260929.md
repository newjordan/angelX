## The cheapest cue that re-routes a loop

`scripts/bench/book-harness/decide/loop_replay.py` takes the request just
after the Nth identical result at 13 live loop points (the 16 loops minus
three file-paging false hits), varies only the cue, and replays it on the
bench's terms, 2 samples each. A reply breaks the loop when its next call
differs (digits masked). Cost is prompt tokens over the raw result.

| cue | where | cost | after repeat 2 | after repeat 5 |
|---|---|---|---|---|
| none | — | 0 | 0/26 | 0/26 |
| `⠇⠁` | result tail | 5 | 0/26 | 0/26 |
| `⛔⠇⠁ ×n` (+ the output's tail) | result head | 10 | — | 0–1/26 |
| `⠇⠁` + its English | result tail | 34 | 0/26 | 0/26 |
| the 0.1.6 paragraph | result tail | 121 | — | 0/26 |
| `⛔⠇⠁` | own user turn | 7 | 6/26 | 11/26 |
| `⛔ Do not repeat the previous tool call.` | own user turn | 11 | 6/26 | 10/26 |
| `⛔⠇⠁ → action` | own system message | 22 | — | 6/26 |
| `⛔⠇⠁` + its legend English | own user turn | 41 | 4/26 | 2/26 |
| `⛔⠇⠓⠁` + the paragraph's force as a page | own user turn | 53 | 3/26 | 8/26 |
| the 0.1.6 paragraph | own user turn | 121 | 18/26 | 12/26 |

1. **Position.** Inside the tool result a cue is read as output: nothing
   there broke a loop, the 121-token paragraph included. The same paragraph
   broke 12/26 as its own turn.
2. **Novelty.** Live (r5, `⛔⠇⠁` as its own turn every second hop), only the
   first of 22–26 turns changed the next call in each looping task: an
   identical cue repeated becomes part of the loop.
3. **Re-routing is not escaping.** Live (r6, a new `⠇⠓` page each turn), each
   new page changed one call and the loop re-formed.
4. Among own-turn cues, 7 tokens did as well as 41–53 of book English; only
   the 0.1.6 paragraph at the second repeat stands out (18/26). With 26
   samples a cell moves about ±5.

## The root cause: the model stopped reasoning out loud

The bench runs DeepSeek with thinking disabled, so the only reasoning the model
does is what it writes before a call. Tool-call turns carrying reasoning text:
Sep 21 55%, Sep 23 69%, the legend build 4%. On the older builds solved tasks
narrated on 72–78% of turns and failed ones on 6–9%. Two changes had removed
it: `09a15bd` (Sep 25) swapped 0.1.6's "you MUST emit 1–2 concise sentences
before invoking ANY tool" for "plain tool calls without routine narration",
and the book (`77dc070`, `b673787`) replaced 0.1.6's second-person advisories
(post-edit logic review on 135/136 tasks, verification recovery, the loop
perturbation) with terse routes or nothing. The loop cues above were treating
the symptom.

Fixes: `3d54a28` and `3a64125` ask for one caveman line before every call
(what the last result showed → hypothesis → check → expected result);
`3efe7c5` ports every 0.1.6 advisory into the book verbatim as pages, each its
own turn, introduced by the legend (inventory: `nudge-port-20260929.md`).
