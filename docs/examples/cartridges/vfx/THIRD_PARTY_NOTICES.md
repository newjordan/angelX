# Optional Bend toolchain and native runtime

The VFX implementation and adapter are original angelX code under `LICENSE`
(MIT). The native executable is compiled with Bend 2.0.39 and incorporates
its Base effects and runtime, under Apache-2.0. Retain this notice and
`licenses/Bend-Apache-2.0.txt` with distributions of the compiled executable.

Source: https://github.com/bendlang/bend/tree/v2.0.39

The build downloads the official release unchanged; the cartridge's own
sources are compiled into it. No Scenario code or media is included.
