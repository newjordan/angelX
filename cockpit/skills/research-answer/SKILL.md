---
name: research-answer
description: Answer research questions using sources, citations, claim support and explicit missing evidence disclosure. Read-only evidence gathering with no code changes or verifier command.
---

Deliver the answer itself as the candidate. Read sources, compare claims, and cite
only sources that support the answer. New sources are progress; repeating the
same search without new evidence is not. Do not invent a verifier for this task.

If the evidence is missing or insufficient to answer the question, state that
explicitly and cite nothing. A missing-evidence answer carries NO citations,
including background links or a sources appendix. Never attach unrelated sources
to an unsupported claim. For a supported answer, place citations by their claims.

This contract applies to answer-only research. A task requiring edits or a
verification command retains the coding completion contract.
