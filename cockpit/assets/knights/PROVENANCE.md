# Knight cast v1

Original artwork generated by Astra with the built-in image-generation tool on 2026-09-15 at the user’s request. No external character likeness or asset source. Native Kimi K3 agents work only on procedural architecture code.

`cast-v1.png` is the unmodified 1278×1230 RGBA original. Runtime `knight_cast.rs` takes fourteen reviewed regions, clears low-alpha fringe and seats them on one 320×350 transparent canvas with the same hoof baseline. The two fourth-column mounted ready poses are excluded: their raised lances violate the atlas margin. The approved source is never displayed as a world plate; all world/ceremony sprites pass through Dotmax.

Runtime grading modestly lifts and caps red/blue heraldic ink so both identities remain readable after Dotmax screening, while preserving black silhouettes and the original source file.

Red sun knight faces right and occupies the left rail. Blue star knight faces left and occupies the right rail. Their roles derive from observed work/travel, never a random pack timer or a reward claim. Mounted, reading, crafting, guard and rest poses belong to this same cast.
