# Tourney artwork

`source/` contains the arena and mounted-knight originals generated with OpenAI's
image-generation tool. `arena-plate.png`, `mounted-knight-pose-sheet.png` and
`poses/` contain their processed terminal assets.

The arena uses a restricted palette. The pose sheet uses a removed magenta key;
the approach and canter crops provide the bundled rider fallback.

[library/](library/MANIFEST.md) contains additional plates, poses, effects and
frame sequences. Sequence metadata is retained with the frames.
