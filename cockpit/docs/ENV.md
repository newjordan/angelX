# angelX-cockpit environment knobs

Every `ANGEL_*` variable the cockpit reads, grouped by subsystem. Defaults are
the built-in values; **`0` usually means "disabled/unbounded"** for the numeric
guards. Nothing here is required — the cockpit runs with none set.

## RL campaigns in a loop

- `rl_campaign` is a native tool from the first active loop iteration, including
  Deli and MoA loops, at every thinking level and schema profile. It does not
  depend on a stall, tool search, or an activation limit.
- The model chooses `run`, `status`, `results`, or `stop`. A run uses the loop's
  current route and defaults to its task and acceptance command; it can also
  measure a research subproblem with an explicit task and real verifier.
- Campaigns run asynchronously in isolated copies. The main loop can continue
  useful work. `/rl`, `/rl status`, and `/rl stop` operate the same controller.
- Results and candidate artifacts survive fresh iterations and process restarts.
  Resuming the same loop recalls its latest results without relaunching them.
  Apply a useful candidate to the main workspace and verify it before submitting.
- An independent audit can approve and install a learned prompt policy. Without
  one, the campaign remains measured exploration. Neither path updates model
  weights or proves that a separate trainer consumed the results.
- Pausing, stopping, completing, or leaving a loop cancels its owned campaign.
  There is no default campaign thinking, hop, token, or time cutoff. Explicit
  loop token/time allowances also cover campaign work; token accounting is
  estimated, as in the parent loop.
- Deli deliberates before its first action pass, then forwards native tools and
  their results. It does not repeat all deliberation rounds after each tool call.
- The model can also select a Deli excursion with
  `consult_model({"method":"deli","club":"self","prompt":"...","rounds":6})`.
  Its synthesis returns to the current turn, which can continue with ordinary
  tools. `rounds` is optional and defaults to `ANGEL_DELI_ROUNDS`; this does not
  change the loop mode. Cancellation reaches deliberation and synthesis.
- Active loops advertise `consult_model`, `spawn`, and `continual_harness`
  alongside `rl_campaign`, including compact schema profiles. Deli, MoA, and
  supplemental note retention therefore do not depend on a discovery shortlist.

Example model call: `rl_campaign({"action":"run","rounds":1,"group":3,"samples":2})`.
Use `results` for retained evidence, and submit when there is a verified winner.

> A test reports new `ANGEL_*` literals that lack an entry here.
> `ANGEL_DOC_STRICT=1` turns that report into a failing release/CI gate; without
> strict mode, documentation drift remains a visible non-blocking warning.

## Agent loop (`harness.rs`)

The optional research-runner client uses `ANGEL_EVALUATOR_SOCKET` (unset by
default): a host-owned private Unix socket for `angel-evaluate full` and
`angel-evaluate status REQUEST_ID`. The runner injects it with
`--worker-evaluator`; it does not grant arbitrary host command execution or
change the cockpit's verification policy.

### Research and sealed-worker controls

`ANGEL_CODING_TRAINING_AUTHORITY_DIR` (unset) enables publication of native
coding-evaluator decisions to the operator-owned authority directory. Recovery
rejects an authority path that overlaps candidate-writable working or scratch
trees, including symlink aliases; an invalid capture configuration disables
capture while preserving ordinary recovery.

### Test fixture names, not operator settings

The documentation scanner also encounters these test-only names. They are not
ordinary cockpit configuration recommendations:

- `ANGEL_WATCH_BOARD_SUBMISSION` makes the fixture board cartridge's configured
  watch adopt that submission id; the board never answers, so the slot stays
  in flight. It has no production reader.
- `ANGEL_DELEGATED_LINEAGE_FIXTURE` is an optional output JSON path for the
  owned native delegate-lineage test. It also writes a `.fixture.json` companion
  identifying the retained test workspace and rollout store. It has no
  production reader and makes no model or submission request.
- `ANGEL_ACP_LIVE_ONE`, `ANGEL_ACP_LIVE_TWO`, `ANGEL_GLM_LIVE_OK`,
  `ANGEL_HARNESS_GLM_OK`, `ANGEL_HARNESS_GROK_OK`, and `ANGEL_HARNESS_TOOL_OK`
  are exact response/output sentinel text, not environment controls.
- `ANGEL_FAKE_GROK_SPAWNS` is a test process-spawn log path;
  `ANGEL_FAKE_GROK_CRASH_ONCE` and `ANGEL_FAKE_GROK_HANG` inject failures into
  the fake Grok process. They are unset outside the fixtures.
- `ANGEL_BUDGET_LEARN_PROBE_MAX_TOKENS`,
  `ANGEL_MAX_TOKENS_CACHE_PROBE_MAX_TOKENS`,
  `ANGEL_PROMPT_CACHE_PIN_CACHE_PROBE_PROMPT_CACHE`, and
  `ANGEL_STREAM_USAGE_PIN_CACHE_PROBE_STREAM_USAGE` exercise synthetic
  per-club token/cache settings. They are unset outside the fixtures.
- `ANGEL_LSP_POSTCHECK` appears as a disabled compatibility fixture setting;
  the active production source has no reader for this spelling.

## HTTP / resilience (`club.rs`)

| Variable | Default | Purpose |
| ----------------------------------- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ANGEL_HTTP_TIMEOUT`                | `60` (s)                   | Socket read timeout. It bounds the whole response for buffered calls and one blocking read for SSE calls. The bounded default prevents a silent provider socket from parking the foreground turn; `ANGEL_STREAM_TOOL_SILENCE_SECS` defines the narrow local-tool exception below.                                                                                                                                 |
| `ANGEL_STREAM_STALL_SECS`           | `45` (s)                   | Streaming data deadline: a live SSE stream must deliver a real chunk this often. Tool HTTP requests also use this as their body idle bound, including in YOLO; each received body chunk resets it. The turn deadline remains an independent absolute bound. Tool HTTP supervision polls every 25 ms (up to two ticks for a forwarded cancel signal), then kills and reaps its request helper. Keep-alive comments reset the plain read timeout but not this one, so a server that queues forever while pinging fails loudly instead of hanging the turn. Blank frames are not progress: an empty `choices` array, a keep-alive comment, or a tool-call envelope carrying no id, name, or arguments never resets the deadline, and none of them counts as completion or token progress. A stall that arrives after partial prose is classified exactly like any other missing terminal event, so the hop may be replayed with the partial retracted. Detection happens at the next completed read, so a socket that stops sending even keep-alives is reported once the read deadline (`ANGEL_HTTP_TIMEOUT`) has also elapsed. `0` disables. |
| `ANGEL_STREAM_HARD_SECS`            | `900` (s)                  | Wall-clock deadline for one streaming provider attempt, even when real SSE deltas keep arriving. ## Autonomous loop (`loop_ctl.rs`)

`/loop` drives successive full agentic turns at a goal/task until a stop condition.
Budgets guarantee termination. On a stall it brings progressively more of the engine
to bear — **Local → Swarm** (local Mixture-of-Agents, automatic) **→ SOTA** (a frontier
model, only behind an approval modal). `/loop deli` drives each iteration through the
**deli** deep-think-over-time method (composes with any tier). Done-detection is hybrid:
a goal's pinned `cmd` (`/goal cmd <check>`) is run and, when it emits a libtest summary,
scored through the **LEVI / reinforce** verifiable reward (`CompositeReward::code_health`)
as ground truth — guarded against reward-hacking (zero-test green rejected; a green whose
pass-count regresses below the pre-edit baseline rejected). Otherwise the model's
`LOOP_DONE` is "claimed". The pinned command guards against the _model_ swapping the
predicate mid-run; the operator can re-pin a live run with `/goal cmd <check>` (the old
baseline is dropped). `/goal go` starts (or resumes) the loop at the active goal. State
persists to `~/.angelX/loop.json` (crash → resumes
`Paused`); with `ANGEL_LOOP_STATE_DIR` set it also mirrors a deli-style `state/` dir for
an external watchdog.

## The Cut (authored-diff manifest + machine verdict, `cut.rs`)

Every mutation angel makes earns two labels: the machine's immediately (did the
project still build?) and yours eventually (did the diff survive into a commit?).
Rust writes the authored-change manifest. **On by default**:
an agent that does not check its own work is the thing this fixes.

| Variable | Default | Purpose |
| ------------------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ANGEL_CUT`                     | on             | `0` kills capture. The four mutation tools (`write_file`, `str_replace`, `multi_edit`, `apply_patch`) are wrapped at their one registration site, so capture covers code-mode and delegate writes too.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `ANGEL_CUT_DIR`                 | `~/.angelX/cut` | Manifest location: day shards `authored-YYYYMMDD.jsonl`, one row per authored file per call (redacted with the barrel's redactor; `authored_sha256` digests the text as written).                                                                                                                                                                                                                                                                                                                                                                                                                                                |

| `ANGEL_CUT_VERIFY` | on | `0`/`off` opts out; any other nonempty value is the explicit command at the workspace root. Post-write verification resolves every changed source path and runs each concrete
command/directory/source plan once per fully dispatched tool batch. Separate
crates and file-scoped syntax checks remain distinct. Authored rows retain their
own file provenance, with `verification_id` and `shared` identifying one reused
receipt; rollout reward observations count that execution once. Forge summaries
report execution counts separately from per-fragment machine labels. A subsequent
batch always invalidates the prior verdict for its changed scope before checking.

Only the default Cargo check can defer a small, valid package manifest that has
no declared or conventional target yet. A complete scaffold is checked on its
next source edit; a normal answer forces any remaining deferred check, independently
of optional verify-before-done controls. Interrupted scaffolds and later writes
whose verifier is cancelled, timed out or unavailable remain unverified and cannot
inherit an earlier passing reward. Explicit `ANGEL_CUT_VERIFY=0` and externally
owned evaluator labels retain their existing semantics. Standalone final-check
receipts use `verification-YYYYMMDD.jsonl` beside authored shards, with a separate
cap of one sixteenth of `ANGEL_CUT_MAX_MB`; they are not authored training examples.
Python defaults compile source bytes without executing them or writing bytecode.

## Test fixtures and receipt markers

These names are recognized by the source-literal documentation check. They are
not additional interactive model controls.

  `ANGEL_NATIVE_TRAINING_FIXTURE_EXPORT` select explicit temporary export roots
  for ignored coding-training fixture tests. Unset by default.

  the ignored experiment snapshot test. Unset by default.
- `ANGEL_NATIVE_USAGE_RECORDED_ENVELOPE` optionally supplies a recorded envelope

- `ANGEL_NATIVE_USAGE_FIXTURE`, `ANGEL_NON_HTTP_USAGE_FIXTURE` and
  `ANGEL_SUPPLEMENTAL_CHAT_USAGE_FIXTURE` are printed receipt prefixes in usage
  contract tests, not environment settings.

  `ANGEL_OWNED_TEST_TOKEN` hold synthetic credentials in redaction tests.
- `ANGEL_PRIVATE_CUSTOM_MODEL_MAX_TOKENS` is a negative-control override in the
  custom-model context-window test; arbitrary environment names cannot invent a
  supported model context limit. `ANGEL_META_MAX_TOKENS` appears only as an
  illustrative short numeric value in a redaction comment.
- `ANGEL_SOTA_SOLO`, `ANGEL_TASK_ID` and `ANGEL_RUN_ID` are deliberately injected
  parent-state values in delegated-lineage tests. They do not replace the
  delegate's own bounded identity and execution contract.

  in auth/error-redaction and persisted-output redaction tests, respectively.
  They are not provider credentials or operator authentication settings.

  Markdown matrix to its fixture evidence directory. Unset by default; not a production logging toggle.
- `ANGEL_NATIVE_VIDEO_FIXTURE` optionally supplies an existing MP4 to the
  feature-gated native-video stage test; the supplied file is not overwritten
  or removed. Unset generates a controlled temporary clip.
- `ANGEL_NATIVE_VIDEO_PROTOCOL` selects `halfblocks` (default) or `iterm2` in
  that test only. Use the documented image-protocol control for the product.
- `ANGEL_NATIVE_VIDEO_DUMP` optionally names that test's PNG output: decoded
  native-protocol pixels or the actual halfblock TestBackend raster. It does
  not capture or prove a physical terminal display. Unset writes no dump.

### Run identity build metadata

`ANGEL_BUILD_RUSTC` is the complete `rustc -vV` output captured by `bin/angelX` at build time (including host triple). `ANGEL_BUILD_PROFILE` is the launcher-selected build profile. Both are compiled into build/run identity; absent values remain `unbound`. They do not select a runtime route or constrain a run.

- `ANGEL_GO_BIN`: Optional absolute native Go executable pin for typed `run_tests` (`runtime: go`). Task-writable paths and scripts are refused; the default probes system Go installations.

### Unproductive streak escalation

- `ANGEL_UNPRODUCTIVE_STREAK_ESCALATE`: completed-hop interval for the `⠇⠛⠃` notice, which the model hears as its own `⛔` turn (the count and the last verifier beside it), at this streak length and at every multiple of it while the streak lasts. Defaults to `8` on every route. Explicit values, including `0` (off), override the default. The progress ledger measures verifiable progress rather than imposing a fixed read-count threshold, so long-form proof, profiling, and repository diagnosis can continue when they are producing new evidence.
- The redirect: at 16 unproductive hops in a task turn outside a competition the model hears `⛔⠇⠛⠉` (0.1.6's mandatory progress redirection, whose stop is gone) and the count starts again. A fixed number (`UNPRODUCTIVE_REDIRECT_HOPS`); nothing stops a turn, and `ANGEL_UNPRODUCTIVE_STREAK_STOP` is no longer read.

### Measured model defaults

The cockpit embeds `docs/telemetry/model-calibration.toml`. Exact model IDs select

### Opt-in formation budgets

`ANGEL_FORMATION_TOKEN_BUDGET` and `ANGEL_FORMATION_WALL_SECS` are unsigned
integer allocations for turn-shared bookkeeping. Unset means no allocation;
zero still admits requests. Identity budgets add these keys when configured.
Each HTTP attempt reserves a conservative wire-byte prompt estimate plus output
allowance, then settles C06 normalized usage. Share sizing retains a useful output
floor even when allocation is exhausted. Unknown usage retains an estimated
charge and a null reported spend; it never stops admission.

The task envelope and graph episode retain the allocation ledger, signed
`remaining`, `over_allocation` and peak `over_allocation_tokens`; the ledger also
reports `current_over_allocation_tokens`. Peak observations survive settlement.
Compatibility fields `reservation_denied` and `budget_exhausted` mean charged
spend exceeded allocation, never that a reservation was denied or work stopped.
Wall overruns set `wall_allocation_exceeded` without setting a provider deadline.
Explicit graph/provider deadlines remain separate. Arithmetic saturation is
marked `accounting_overflowed`; such totals cannot qualify exact-spend evidence.
Providers without an established C06 counting contract cannot qualify equal-token
cohort evidence.

### Tool stdin and idle escalation

Tool sandbox commands default stdin to `/dev/null`; a tool that supplies input may
explicitly override that default. `ANGEL_TOOL_IDLE_SECS` is an opt-in positive
number of seconds without stdout or stderr before a recoverable `tool_idle`
escalation, unless the owned foreground process group has recent output or
sampled Linux CPU consumption. Unset, invalid, or `0` disables this heuristic;
the separate turn idle policy no longer silently creates a tool-kill policy.
The child tree is killed and the tool fails; the turn records `kind: tool_idle`
and the hop in `escalations[]` and lets the model recover. This applies in YOLO
as well. The turn watchdog allows three seconds for a due tool escalation to
settle before its fallback cancellation. Existing earlier timeout policies still
apply. A drain that expires after child exit reports `grandchild_holds_stdout`
or `grandchild_holds_stderr` (`[⡨⠉⠉]` / `[⡨⠉⠙]` on the wire), with capture
explicitly incomplete.

### Verifier runtime pins

`ANGEL_NODE_BIN` and `ANGEL_PYTHON_BIN` select absolute runtime executable paths.
Typed verification additionally requires native images outside task-writable
roots. `ANGEL_CARGO_BIN` selects an absolute direct toolchain `cargo` binary
beside `rustc`, not a rustup proxy; the existing trust and Cargo configuration
checks still apply. Invalid explicit pins do not silently fall back. Restart
Angel after changing a pin. Missing runtimes report `runtime_missing` with the
runtime, lookup description, and installation/pin hint.

### Interactive frame timing

`ANGEL_FRAME_TIMING_LOG` is unset/off by default. Set it to a writable file to
append completed interactive terminal draws as TSV: elapsed microseconds since
logger creation, draw/flush microseconds, and microseconds since the previous
completed draw (`-` on the first row). A comment header supplies the approximate
Unix epoch origin in microseconds. Gaps include event polling, event processing,
and telemetry writes; draw cost excludes the telemetry write. These are product
CPU/terminal-write timestamps, not physical display presentation times. The
synchronous small write adds observer overhead. No terminal text is recorded;
open/write failures are ignored, and the operator owns file retention. The
resize-storm harness copies this scratch log into receipt chunks below 1 MB.

### Graph budget diagnostics

- `ANGEL_GRAPH_BUDGET_TRACE=1`: emit numeric reservation, denial, and settlement JSON to stderr, including node role, requested tokens, remaining tokens before/after, and released allowance. Off by default; contains no prompt or response bodies.

### Startup workspace indexing

`ANGEL_STARTUP_WALK_MS` sets the optional startup workspace-index wall-time allowance in milliseconds (default `500`; `0` returns unavailable/partial evidence immediately). Git enumeration honors `.gitignore` and `.git/info/exclude`, with a 16 MiB metadata capture allowance. Checks between file reads return an explicitly partial index with path counts, elapsed time, and a separate partial digest; a partial digest is never a complete tree identity or fresh-verification claim. The allowance applies to startup indexing, never to the model turn or exact verifier evidence. Filesystem calls and subprocess cleanup can exceed the cooperative deadline.
- `ANGEL_TURN_PHASE_TRACE=1`: emit payload-free `[turn-phase]` stderr breadcrumbs with PID, process-local turn id, monotonic elapsed milliseconds, and the phase being entered. Covers worker startup, context/preflight, provider dispatch/return, tools, hop end, and steer drain; disabled by default. `request_sent` marks entry to the provider adapter, not proof of an HTTP request; correlate with provider receipts. The last entered phase locates an outstanding step. Redirect stderr when running in a terminal to retain traces without disturbing the screen.
`ANGEL_INTERNAL_SANDBOX_STATUS_FD` is a private inherited anonymous-file descriptor set by the execution collector. The single-threaded helper sends sandbox attribution and confinement failures, then closes it before executing a tool. It is not an operator setting. `angel --doctor` probes local Bubblewrap user namespaces and prints host remedies; ordinary denied-userns execution uses Landlock-only confinement with bounded alias copying and explicit unprotected-alias receipts.

Landlock-only alias privatization attempts at most 64 files and 64 MiB per helper launch. Copy errors, exhausted copy allowance, and unscanned subtrees are retained in `aliases_unprotected`; the command proceeds with a transcript notice. Existing shared-temp scan exclusions remain visible in the scan receipt. A command’s own nested Bubblewrap failure is an ordinary tool failure with a doctor hint; only helper-channel Landlock setup failure pauses automatic loop continuation pending host repair.

## L01 unattended-run policy (2026-09-10)

Run caps are operator opt-ins. Headless startup now installs `ANGEL_MAX_HOPS=0`
and `ANGEL_TURN_DEADLINE_SECS=0` only when absent, preserving explicit CLI/env
values. Descendant turns also default to unlimited hops. The task prompt asks
for all requested deliverables after a green verifier rather than forcing an
immediate answer.

No harness heuristic stops a turn or denies a call or an answer: spin, error,
poll, cycle and streak detectors throw braille routes instead (see *Book of
behaviors*).
`ANGEL_PROVIDER_RETRIES` is unbounded when absent; an explicitly supplied integer
retains the bounded retry policy. Default provider failures retry the same hop
with cancel-aware backoff and one notice per attempt; permanent account/config
failures (authentication, invalid request/model, billing, exhausted long-window
quota) still fail after one attempt with an actionable message instead of
looping, and a stream that dies without a terminal event is always recoverable
whether or not it had already streamed partial text. A permanent failure
outranks that classification even when the same error carries stall context. A
tool-bearing agent-graph node recovers inside its own turn, so the graph retries
only toolless nodes and an explicit retry budget is never spent twice. A replay
is a fresh provider request: output streamed on the failed attempt is not free,
and the ledger keeps every attempt.

`ANGEL_DESCENDANT_CALL_BUDGET` defaults to 0 (unbounded); explicit values 1–1024
retain cumulative admission. `ANGEL_SPAWN_TIMEOUT` and spawn `timeout_secs`
default to 0 (unbounded); positive values are honored without silent clamping.
`ANGEL_SWARM_WAVE_DEADLINE` defaults to 0; quorum still completes a wave.
`ANGEL_GRAPH_DEADLINE_SECS` already defaults to 0.
`ANGEL_TURN_IDLE_TIMEOUT_SECS` is off by default, including calibrated model
routes; explicit positive values still abandon an idle turn.
Ordinary handoff RL launches have no duration/token/roll caps. Explicit Podrace
selection retains its five-day profile. Campaign round defaults are unbounded
(`policy.max_rounds=0`); round history no longer creates a 128-round stop.

### Still-image inspection (Scryglass)

Open an existing local image through the artifact list/Scryglass media reveal.

pans. Right-click or **Fit** resets. The compact footer has **−**, **+**, **Fit**,
**Back** and a zoom percentage relative to Fit (not a native-pixel 1:1 claim).

`0` fits. Drafts and slash commands retain their keys. **Esc** / **Back** closes
the overlay and returns to the previous world route; active-turn Esc still stops
work first. F4 uses the existing Scryglass focus layout.

Inspection pins once: automatic reveal timers/tools cannot replace the inspected
image. First-load hit targets are disabled. While **updating**, the last painted
same-source/request/geometry image remains visible and owns pointer coordinates;
wheel/key/drag input accumulates into the desired view, not dropped encoder ticks.
Release a drag anywhere to end it; resize, focus loss, modals and route exit also
cancel capture. Footer **Fit 100%** / **N% inspect (of Fit)** is relative to Fit,
not a native 1:1 claim. These are image controls, not world navigation.

Source detail is sampled off-thread from one bounded decoded image, not the
portrait thumbnail cache. Area-coverage downsampling antialiases thin strokes;

<=128MiB decoded source; encoding/retained protocol costs scale with output, not
source dimensions. The existing 64MiB encoded / 32MP source limits still apply.

draw with the **same local picker** for encoding and cache/input geometry. Zero
or unavailable physical geometry honestly falls back to 2×4-density halfblocks;
there are no new stdin escape probes or global picker/environment mutations. Video is **existing optional playback only**, not
part of these inspection controls.

actions are `zoom_in`, `zoom_out`, `left`, `right`, `up`, `down`, `fit`. This never
opens a file. `ui_inspect` reports `scryglass.image_inspector`; wait for
`loading:false` and a non-null `viewport` for the latest desired view. During
`status:"updating"`, `painted` gives the old displayed zoom/pan, while top-level

## Book of behaviors (2026-09-26)

The harness speaks to the model only in braille, through the book of behaviors
(`cockpit/src/agent/harness/book/`, one chapter file per chapter). Every word
lives in the ledger, which the model reads on demand; the harness sends codes,
never prose, and times them: the system prompt is the entry warpath (the
personality type, e.g. `⠽⠃⠍⠁⠽⠑` for a headless rapid repair with teammates),
the first tool result of a turn carries the hygiene cue (`⠺⠁⠺⠉⠧⠊`), and after
that a cue appears only when the model's latest actions make it relevant
(serial single reads `⠺⠛`, a clean test run after edits `⠺⠓`).

Addresses nest. A chapter is a braille letter k–z; a section attaches to it as
a braille digit (⠁1 ⠃2 ⠉3 ⠙4 ⠑5 ⠋6 ⠛7 ⠓8 ⠊9 ⠚0) and is a route; a page
attaches to a section as a second digit. A page is one sentence of the prompt
it came from, verbatim — a section's pages rebuild that block exactly, and a
test pins every original hint (`every_original_hint_is_rebuilt_verbatim_from_its_pages`).
A **warpath** is up to three routes, six cells, read in order: `⠧⠁⠧⠋⠟⠁` is "the
last test run is red, the edits are untested, if stuck take the deli route".
`read_file ledger://<cells>` decodes a chapter, a section, a page or any run of
addresses; a personality type renders every section it bundles in full;
`ledger://` is the table of contents. The only standing direction is one
clause in the `read_file` schema. Detectors throw the routes today; the tree is
shaped for a small router model to throw them later.
