# Bestiary

Characters drawn once at native game size in the Delve's inks (one character per
pixel, `.` clear), facing right, with a 1-pixel dark outline. Each one rigs into
all 13 clips with `spriterig.smartfit`: `frog` (frog knight), `mage` (skeleton
mage in a robe), `ogre`, `skeleton`, `imp` (winged), `knight` (plumed), `witch`
(pumpkin-headed), `golem` (lava), `ghost`, `goblin`, and two at the game's 16 px
summon size, `imp16` and `squire16`. They are the fit's test fixtures and the
reference for what a rig-ready sprite looks like.
