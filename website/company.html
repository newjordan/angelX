The work

A loop that keeps what passes

angelX is a terminal coding agent and a research harness. On a repository it asks before it runs a command or edits a file. On a longer goal it proposes a change, measures it, checks it, and keeps what passes the check you set.

  1. 01

    Propose

    A goal or a loop names the change. /goal keeps the objective. /loop bounds time, iterations and tokens.

  2. 02

    Implement

    Edits land in the real tree, anchored to the file's current content, and only after you approve them.

  3. 03

    Measure

    The agent runs the checks you named. Paired benchmark samples can be compared with benchmark_compare.

  4. 04

    Validate

    A task's tests, a verifier, or a review gate decides what counts. A finished answer is not itself the proof.

  5. 05

    Promote

    What passes can stay. What fails is reported with the tool receipts from the turn.

The behavior above is the product described in the README and feature evidence. Published measurements, with their dates and settings, are on the evidence page. This page does not add a separate scoreboard.
