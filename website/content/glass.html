The Glass reel.

Twelve point eight seconds of angelX's GPU terminal. The wide film plays on a wide window; the portrait film is the same reel for a narrow window. Both files are on this origin. Press play to start. Nothing plays by itself.

{{GLASS_REEL}}

The opening line in the film is “angelX glass — the cockpit's text is one layer of a GPU compositor.” The reel then shows text styles, a color ramp, braille, and a small 3D scene. Each file is H.264 with an AAC audio track, 30 fps, 384 frames. The still behind the player is one frame of that same file, so the player has a picture before the video bytes arrive.

What ships with angelX

Every prebuilt install also installs glass, linked as glass next to angelX. The installer never replaces a glass you already have. Run angelX inside glass and pictures, video and charts show in the terminal too.

The 0.2.7 release notes record the measurements taken against kitty 0.49.2 on one machine. They are not a new run for this page:

  • First output on screen in 46.1 ms (kitty 185).
  • A key press reaching the program while it floods output in 3.0 ms (kitty 38.6).
  • The window on screen in 31 ms (kitty 73) and the program running in 39.5 ms (kitty 193), medians of 16 runs through Hyprland on a headless output.

The repository README rounds the first of those to 46 ms. Host CPU, GPU and memory for the terminal comparison are the machine named in the Glass terminal guide and the 0.2.7 release notes. Only kitty has been measured there.
