angelX · OmniSpace Technologies

The terminal coding agent.

angelX works inside your repository with the models you choose, asks before it runs a command or edits a file, checks its work before it reports done, and keeps what it learns about your project.

Install angelX Read the docs Source on GitHub
{{GLASS_REEL}}
curl -fsSL https://raw.githubusercontent.com/newjordan/angelX/main/install.sh | sh

Then open a new terminal and run cd your-project && angelX. Linux x86_64 and arm64 (glibc 2.31 or newer) and macOS on Apple silicon. Full install.

In the cockpit

Five things it does on every task

This is the working product, documented in the repository and installed from this site.

  1. 01

    Choose a model

    /model lists every connected route. /setup finds Ollama, LM Studio, llama.cpp, vLLM, an API key, or a ChatGPT or Grok plan login.

  2. 02

    Approve actions

    Commands and edits arrive as capsules: approve one, approve the rest of the turn, or deny.

  3. 03

    Check the edit

    Each edit is anchored to the file's current content and shows its byte change before it lands.

  4. 04

    Check the result

    The agent runs the checks and reports with receipts: every tool call, its time and the model route.

  5. 05

    Keep going

    /goal sets a durable objective. /loop runs it within time, iteration and token limits.
