Install

Install angelX

One command for the prebuilt. The same installer is install.sh in the repository. It downloads a release archive from GitHub, checks SHA-256, and only then puts angelX on your PATH.

curl -fsSL https://raw.githubusercontent.com/newjordan/angelX/main/install.sh | sh

Open a new terminal window, then:

cd your-project && angelX

Where it runs

  • Linux x86_64 and arm64, glibc 2.31 or newer (Ubuntu 22.04, Debian 11, RHEL 9 and later). musl systems such as Alpine are not covered by the prebuilt.
  • macOS on Apple silicon. An Intel Mac, including one that is not running the shell under Rosetta's translated arm64, has no prebuilt yet.
  • The prebuilt needs bash and tar, and either curl or wget.

This repository's current release is v0.2.86. With no version set, the installer takes the latest GitHub release. ANGELX_VERSION=v0.2.86 selects that tag. Release archives: github.com/newjordan/angelX/releases.

What the installer does

  • Downloads angelX-<platform>.tar.gz and SHA256SUMS from https://github.com/newjordan/angelX/releases/latest/download (or from the tag you set). The platforms are linux-x86_64, linux-arm64 and macos-arm64.
  • Refuses to install if the checksum does not match, the archive is not an angelX prebuilt, or the binary does not run on this machine.
  • Unpacks into ~/.angelX/releases/<version>-<platform> and points ~/.angelX/current at it. Running it again upgrades in place. Keys in ~/.angelX/angel.env, sessions and cartridges stay put.
  • Links ~/.local/bin/angelX and angelx. ANGELX_HOME and ANGELX_BIN_DIR change those paths. ANGELX_ARCHIVE installs a package file you already downloaded.
  • Links glass beside angelX when the package includes it, and never replaces a glass you already have.
  • If ~/.local/bin is not on PATH, adds it to the shell startup file. ANGELX_NO_MODIFY_PATH=1 prints the line instead. Fish gets fish_add_path instructions.

angelX update installs the latest release later. The first launch opens a setup menu. Type /setup, or run angelX setup, to change the model. The menu is documented in Model setup.

Build from source

You need Rust and Cargo, C/C++ tools, Bash, Node.js and Python 3. On macOS: xcode-select --install, then Rust from rustup.rs.

git clone https://github.com/newjordan/angelX.git
cd angelX
./bin/angelX

Source launches use the incremental fast profile. ANGEL_FAST=0 ./bin/angelX is a release build. ANGEL_NO_BUILD=1 ./bin/angelX reopens the existing fast binary without compiling. The development workflow is in CONTRIBUTING.

To compile with Blaze instead of Cargo, install it once with python3 scripts/runtime/install-blaze.py, then launch with ANGEL_BUILD_BACKEND=blaze ./bin/angelX.
