/commands

Enter commands in the cockpit composer. /help all shows built-in help; Tab completes a command. Brackets below mean optional arguments. Commands that launch model work use the configured routes and can incur provider charges.

/graph run polyglot-departments <task> assigns eight non-game application departments of roughly 25,000 Rust lines each. Their analysis nodes can run in parallel; the graph orders code-writing nodes because they share a workspace, then integrates and reviews the result. The graph is a starting assignment: its line counts are approximate and its path boundaries are instructions to the agents, not filesystem-enforced restrictions.

/layout reload-manifests reads all six files in the active resource root's cockpit/modules/ directory. It applies them together only if every file parses and retains its registered ID and native kind; an error leaves the current configuration in place. Current pane geometry, focus where available, and operator activation choices survive the reload. Data-source requirements take effect immediately; default rectangles and startup activation do not change existing surfaces. The embedded manifests remain the startup defaults, so run the command again after restarting to apply disk edits. This reloads surface configuration, not executable code. Finish saving the files before invoking it; the command reads each file once and does not coordinate concurrent editors.

Compatibility names with limited behavior: /setup-default-sandbox and /sandbox-add-read-dir only display sandbox status; /approve and /test-approval direct you to /approvals; /theme does not change the palette. /logout gives credential-location guidance. /ide, /app, /plugins and /feedback have no corresponding cockpit subsystem. /selftest aliases /solo.

Sources: parser and completion, command dispatch, built-in help.

Walking the map

Click the Realm map, press p on it after F4, or type /world walk. Your own knight steps out beside the harness's knight, who keeps working.

  • Arrows or WASD walk. A click on the map walks there by road; a click on a building walks to its door.

  • At a door a sign says where it leads. Enter, F or Space goes in (below); other places only say their name.

  • Esc leaves. While a turn runs, Esc stops the turn first. Walking also ends when the map leaves the pane or the pane loses focus.

  • While your knight is called to the Delve, a click on the map still goes through its gate; /world walk steps onto the map instead.

Copying work shown in Stage

  • Right-click the Stage artifact (or /copy stage, /copy stage path) copies the displayed artifact's absolute local path or remote URL. It does not upload the file or copy image pixels.

  • Shift+right-click a local report (or /copy stage text) copies the loaded local document preview, with the same control-character escaping and truncation markers as Stage. It does not fetch remote pages. Wait for a document to load before using it.

  • These commands reuse OSC-52 clipboard delivery and always write recoverable fallbacks: ~/.angelX/stage-location.txt and ~/.angelX/stage-document.txt. The receipt distinguishes a clipboard request from confirmed delivery.

  • With no media overlay displayed (world, lessons, catalog, or an empty Stage), copying Stage fails explicitly rather than copying an agent reply or a previously displayed artifact.

  • Image inspection keeps its Fit button and Ctrl+right-click reset gesture. Plain right-click copying leaves the image zoom, composer draft, and active model turn unchanged.

  • Right-clicks in other panes, modal dialogs, or PTY-owned mouse regions retain their existing behavior. Some terminal configurations reserve Shift+mouse gestures; /copy stage text remains available there.
